Offline installers for the optional components (used by "一键安装"; never installed automatically).
Each is used only if its SHA-256 matches the value pinned in NyaRemoteControl; otherwise it is downloaded.

For this computer as a host ("本机 → 可选组件"):
ViGEmBus_1.22.0_x64_x86_arm64.exe          ViGEmBus, BSD-3-Clause    https://github.com/nefarius/ViGEmBus
USBip-0.9.8.1-x64.exe                      usbip-win2, GPL-3.0       https://github.com/vadimgrn/usbip-win2 (source: same page)
VirtualDisplayDriver-x86.Driver.Only.zip   Virtual Display Driver, MIT  https://github.com/VirtualDrivers/Virtual-Display-Driver

For controlling other computers (USB passthrough, the session's USB panel):
usbipd-win_5.3.0_x64.msi                   usbipd-win, GPL-3.0       https://github.com/dorssel/usbipd-win (source: same page)

VB-Cable is not redistributable; it is downloaded from vb-audio.com when you choose to install it.
